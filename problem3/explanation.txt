10. ROWS GENERATION IMPROVEMENTS (Lines 63-74 vs 47-62)
================================================================================

ORIGINAL (Lines 63-74):
const rows = sortedBalances.map((balance: FormattedWalletBalance, index: number) => {
  const usdValue = prices[balance.currency] * balance.amount;
  return (
    <WalletRow 
      className={classes.row}
      key={index}  // ❌ ANTI-PATTERN: Using array index as key
      amount={balance.amount}
      usdValue={usdValue}
      formattedAmount={balance.formatted}  // ❌ Property doesn't exist on WalletBalance
    />
  )
})

ISSUES:
1. Wrong type: FormattedWalletBalance instead of WalletBalance
2. Using array index as key (React anti-pattern)
3. Accessing non-existent 'formatted' property
4. Not memoized - recalculates on every render even if data unchanged

FIX (Lines 47-62):
const rows = useMemo(() => {
  return sortedBalances.map((balance: WalletBalance) => {
    const formattedAmount = balance.amount.toFixed();
    const usdValue = prices[balance.currency] * balance.amount;
    
    return (
      <WalletRow
        className={classes.row}
        key={balance.currency}  // ✓ Using unique identifier
        amount={balance.amount}
        usdValue={usdValue}
        formattedAmount={formattedAmount}
      />
    );
  });
}, [sortedBalances, prices]);

IMPACT:
✓ Wrapped in useMemo for performance
✓ Correct dependencies [sortedBalances, prices]
✓ Using balance.currency as key (unique identifier)
✓ Formatting done inline where needed
✓ Correct types throughout
✓ Only recalculates when sortedBalances or prices change
